# App 4 — Travel Blog

Vanilla-JS scroll-driven animations with streamix DOM operators.

## What it demonstrates

- **`onAnimationFrame`** — smooth interpolation loops
- **`onIntersection`** — reveal-on-scroll triggers
- **`fromEvent`** — focus, blur, mouseenter, mouseleave streams
- **`merge`** + **`debounce`** + **`filter`** + **`tap`** — coordinated animation state

## Run

```bash
ng serve app4
```
